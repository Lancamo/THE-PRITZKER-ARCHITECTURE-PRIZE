# 深圳 · 普利兹克建筑奖得主作品分布

10 位普利兹克建筑奖得主在深圳的 11 件建筑作品，标注在一张高精度深圳底图上。
双击 `index.html` 即可运行，不需要服务器、不依赖 CDN。

---

## 本次改动的两件事

### 一、底图换成真实精度的地理数据

原来的底图是阿里云 DataV 的市级行政区划，全域只有 2911 个点，海岸线被抹成
平滑弧线——大鹏半岛、深圳湾、内伶仃岛的形状都是失真的。

现在换成 **OpenStreetMap 的行政边界与海岸线**，重建后的底图包含：

| 图层 | 内容 | 作用 |
|---|---|---|
| 海域 | 珠江口、深圳湾、大鹏湾 | 水陆分色，深圳的半岛形状才读得出来 |
| 周边陆地 | 香港、东莞、惠州 | 浅灰压底，让深圳的白色轮廓浮出来 |
| 山体 | 120m / 200m 两级 | 梧桐山、七娘山、羊台山、塘朗山等地形骨架 |
| 水体 | 63 处水库湖泊 | 深圳水库、铁岗水库、清林径水库等 |
| 区界 | 9 个行政区 | 比市级边界更细的分区信息 |
| 市界 | 深圳市域轮廓 | 主轮廓线 |

**精度校验**：按底图几何算出的深圳陆域面积为 1955 km²，官方公布约 1997 km²，
偏差 2.1%。逐区核对（福田 72.9 / 南山 174.5 / 罗湖 78.8 / 盐田 76.1 km²）
均与公开数据吻合。

数据源：
- 行政边界、海岸线：OpenStreetMap（ODbL 许可）
- 地形高程：SRTM 30m（NASA / USGS 公开数据）
- 投影：等距圆柱，经度乘 cos φ，城市级尺度无可见变形

### 二、标记布局：位置归位置，注记归注记

**原来的问题**：建筑 logo 被引线拉离真实位置去避让，偏移量随密度增长，
最外层的标记被拉开数十像素。在城市级地图上 1px ≈ 78m，几十像素就是几公里
的误差——图上一个点说「在这里」，实际在几公里外。而且标记散得很开，
读不出「哪里密集」。

**判断依据**：福田 CBD 三件作品（深圳文化中心、深交所、南方博时）实测坐标
两两相距只有 **172m–655m**；蛇口三件（海上世界、K11 ECOAST、太子广场）
两两相距 **550m–1.47km**。在地图上分别只有 2–8px。**任何「不重叠」的展开方案
都是在伪造地理**——三个 31px 的 logo 要真正互不重叠，得占 90px 以上的跨度。

**现在的做法**——分两层，各司其职：

1. **位置层（建筑 logo）**：严格锚定实测坐标，**永不位移**。
   相邻作品的 logo 允许重叠，簇内沿对角线各错开 0.19 个标记直径，并加白色
   描边显出层叠关系（像一叠硬币）。最外侧标记的位移 = **0.34 × 标记直径**，
   换算成地理距离是 **≈820m 的定值**——不随视口大小变化（因为标记尺寸和
   地图缩放同步变化，比值恒定）。

2. **注记层（建筑师头像）**：头像是注记、不承担定位，因此可以在簇的下方
   **水平排成一行**，顺序与 logo 的错位方向一致，对应关系可自行推断。
   头像之间还跑一遍**碰撞避让**（只推 y 不推 x，保持行是一条水平线），
   并且会主动避开**别人的 logo**——因为 logo 是位置层，被头像压住就等于
   那件作品在图上消失了。避让后总位移限幅在 1 个头像直径内。

3. **静态图面上没有任何引线**。头像与位置的关系只在**悬停时**动态建立：
   该作品放大置顶、其余淡化，并用一条虚线直接指向它的实测坐标点。

对比：

| | 原来 | 现在 |
|---|---|---|
| 位置误差 | 被引线拉开数十像素（约数公里） | 0.34 × 标记直径 ≈ **820m** |
| 图面引线 | 11 条静态引线 | **0 条** |
| 头像重叠 | 未处理，簇大时互相压住 | 任意视口下 **0 处重叠** |
| 位置与识别 | 混在一起 | 分层，各自负责 |

### 三、聚类阈值是算出来的，不是拍的

头像行只对「地理上同属一处」的作品成簇。阈值必须同时满足两个实测条件：

| 约束 | 实测距离 | 换算地图单位 |
|---|---|---|
| 必须 **大于**，否则蛇口三件被拆散 | K11 ↔ 太子广场 1.47km | 18.8 单位 |
| 必须 **小于**，否则歌剧院被误并进蛇口 | 海上世界 ↔ 深圳歌剧院 2.57km | 32.8 单位 |

可行窗口 18.8–32.8 单位，取中点 **26 单位（约 2.0km）**，两侧余量最大。
结果：福田三件、蛇口三件各成一簇，其余 5 件（大疆天空之城、汉京中心、
荟同学校、华会所、深圳歌剧院）各自独立——歌剧院离蛇口 2.5km 以上，
不该和蛇口算一处。

> ⚠️ 阈值必须用**地图单位**定义、再乘 `scale` 换算成像素。
> 不能写成 `logoD × 系数`：`logoD` 在 `resizeAll()` 里有 17px 下限，
> 窗口一矮就被托底，阈值会跟着膨胀到 2.7km，歌剧院就又并回蛇口了。

## 文件结构

```
index.html              主页：地图 + 标记 + 悬停卡片 + 底部索引
detail.html             详情页：?id=xxx，含迷你定位图
assets/
  map-base.js           底图矢量数据（236KB，由脚本生成，不要手改）
  data.js               全部作品内容 —— 要改内容只动这个文件
  app.js                渲染与交互逻辑
  style.css             样式
  avatar/               建筑师头像（10 张，400×400）
  portraits/            头像原图
  photos/               建筑实景照（8 张）
```

## 修改内容

`assets/data.js` 里是 11 个自解释的对象。加一件作品只需补一个对象，
地图点位、悬停卡片、底部索引、详情页会全部自动生成：

```js
{
  id: 'xxx', name: '中文名', en: 'English Name',
  architect: '建筑师', architectEn: 'Name', prizeYear: 2019,
  lat: 22.5494, lon: 114.0520,        // ← 实测坐标，标记位置由它决定
  year: 2007, district: '福田区', type: '文化', status: '建成',
  tagline: '一句话', desc: '正文…', facts: [['竣工','2007'], …],
  logo: '<path d="…"/>',               // 24×24 视窗的线条剪影
  avatar: 'assets/avatar/xxx.jpg', photo: 'assets/photos/xxx.jpg'
}
```

> 标记坐标不是写在 `data.js` 里的，而是 `map-base.js` 的 `sites` 表。
> 加作品时需同步往底图脚本的 `SITES` 表里加一行再重跑，或直接改 `sites`。

## 换一座城市

底图由三个脚本流水线生成，改开头的城市编码与范围即可重跑：

```bash
python3 build_base.py     # OSM 边界 + 海岸线 → 海陆掩膜 → 区界裁切 + 地形 + 水体
python3 emit_svg.py       # 投影 + 分级简化 → 输出 assets/map-base.js
```

脚本已存进技能 `geo-distribution-map`（`scripts/` 目录），含参数说明与踩过的坑。

## 已知取舍

- **龙岗区面积偏大**：OSM 的龙岗区包含大鹏新区（行政上大鹏是功能区、
  隶属龙岗），因此底图上大鹏半岛归在龙岗区内，没有单独边界。
- **三件作品无实景照**：荟同学校、深圳歌剧院（在建）、蛇口太子广场在公开
  渠道没有可用的授权图片，详情页用「大号剪影 + 说明」版式，没有硬凑无关图。
- **logo 是建筑轮廓剪影，不是品牌标识**：深交所的悬挑裙摆、汉京中心的外置
  核心筒、大疆的非对称悬空箱体本身就是最强的识别符号，且避免了商标使用问题。
