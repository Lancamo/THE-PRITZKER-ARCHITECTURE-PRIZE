# 普利兹克建筑奖可视化站

> **版本：v4.0.0（2026-09-13 首发）** — 本仓库为普利兹克建筑奖展示站的源码、数据与构建产物。
>
> 在线预览：https://the-pritzker-architecture-prize.vercel.app

一座**线上档案馆**：以普利兹克建筑奖 48 届完整数据为骨、单色编辑排版为皮，把「谁获奖、为什么、留下了什么」摊在一张可滚动、可点击、可逐届深入的长卷上。

- 形态：自包含的静态网页（`dist/index.html` + `assets/`，断网双击可开）
- 气质：暖象牙 × 近黑的双色体系，**照片是页面唯一的色彩来源**；全文仅一种主题色（克莱因蓝）且只作交互反馈
- 规模：48 届（1979–2026）· 54 位得主 · 24 个国家与地区

## 三个页面

### 1. 首页 `#/`

**Hero（首屏）**
- 白色巨题「普利兹克建筑奖 / THE PRITZKER PRIZE」、统计数字（48 届 / 54 位得主 / 24 个国家与地区）
- 评审辞金句与同届代表作照片**成对轮播**（同一计时器、同帧切换，图文不错位）
- 右侧青铜奖章 3D：拖拽 1:1 跟随、松手按动量吸附、点击翻转，键盘 ←→ / Enter / Home 可操作
- LOGO 随首屏滚动页内呈现

**数据总览（双图）**
- 图 A · 得主国籍分布：灰阶 voronoi，同一大洲连成整片（洲级灰阶 + 粗缝 + 洲名），洲内按国家拆块，面积 ∝ 人数
- 图 B · 代表作地理分布：极简世界点图，全部大洲完整落在框内，菱形点大小编码作品数量
- 大洲图例与选中状态排在两图下方同一行

**时间轴总览（核心交互）**
- 一屏看全 48 届：横轴贯穿 1979–2026，菱形节点 = 届次
- **悬停某届**：以该届为中心展开「±5 年」窗口，人名、代表作、年份一并加深，并由窗口中心 1.0 向边缘 0.5 渐隐；指针移动窗口跟随
- **三个数据图层**（可切换）：
  - 流派底带（常驻）：现代主义 → 后现代 → 高技派 → 解构 → 地域复兴
  - 师承谱系：7 组师徒连线；指针在轴外时全部点亮，移入后按窗口强调、窗口外的「另一端」届次点亮
  - 年龄：节点上下浮动成「年龄地形线」，上方作品名让位给年龄点与数字

**联动规则**
- 悬停图中某国 / 某地点 → 时间轴同步预览；点击 → 锁定（其余压暗、命中放大、自动滚入视野，状态写入网址 `#?s=country|中国` 可分享），ESC 或点空白解除
- **悬停时间轴某届 → 两张数据图点亮该届 ±5 年窗口内涉及的全部国家与作品所在地**
- 点击时间轴节点 → 进入时间轴档案并定位到该届

### 2. 时间轴档案 `#/timeline/年份`

墨底长卷，一根竖向时间脊贯穿全程，逐届展开：

- 年份钉（滚动触达时弹跳）、肖像与官方项目照片（轻微视差）
- 姓名（中英）、生卒、获奖年龄、事务所
- **生平**：英文全量；有中文译文的届按「英文段 + 其中文译文段」逐段对照；「展开生平全文 / 收起」互斥（展开时钉住阅读位置不跳动，收起时回到该届位置）
- 评审辞短引、代表作列表、进入「单届全档」的入口
- 交互：顶端进度线随阅读推进、`←→` 逐届跳转、档案顶端继续上滑回到首页

### 3. 单届全档 `#/laureate/年份`

- Hero：肖像 + 巨型姓名 + 届次 / 国籍 / 生卒 / 获奖年龄（竖构图肖像自动适配版式）
- 基础信息栏：届次 / 国籍 / 生卒 / 获奖年龄 / 事务所（五格）
- **评审辞**：短引金句（中文思源黑体加粗；中英取同一位置的前 N 句，**首尾同点**）+ 全文（按官网分段，英文段接其中文译文段）
- 代表作 `[01]`、`[02]`…：全幅 / 半幅不对称排布，含城市·国家、建成年、影像署名
- 冷知识（如有）、上一届 / 下一届巨字导航
- 顶部：「在时间轴档案中定位」（紧贴品牌标；压在照片上时按背景明暗自适应取色）与「返回 Index」

## 设计与工程要点

- **单色数据体系**：数据层只用黑 + 透明度阶梯（100 / 70 / 45 / 25 / 12%）+ 白 + hairline；维度区分靠透明度 → 大小 → 位置 → 形状，不用彩色
- **字体**：展示衬线 Fraunces、标题 Outfit、数据/图注 IBM Plex Mono、正文 Inter；中文标题与强调用思源黑体（700/900）、正文用思源黑体 Light（300）——全部按**全站用字**做子集内嵌，任何一页都不会缺字回退
- **自包含**：字体、图片、脚本全部本地化于 `dist/index.html` + `assets/`，可离线打开
- **可达与克制**：键盘可遍历与操作、图片 blur-up 渐入、全部动效提供减弱动态（prefers-reduced-motion）降级

## 打开与重建

```bash
# 直接打开构建产物（双击亦可）
# 站点目录下的 dist/index.html

# 本地预览（推荐；详情页背景取色需要 http）
python3 -m http.server 8792        # 在站点目录起服务，打开 dist/

# 重新构建（改样式/交互后）
python3 tools/build.py
```
